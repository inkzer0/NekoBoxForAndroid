# 相比原版的更新

本 Fork v1.4.3 基于原版 NekoBoxForAndroid 1.4.2，主要更新如下：

- **内核升级**：迁移至官方 SagerNet/sing-box v1.14.0，并适配现有配置格式与 App 接口。
- **Remote Rule Set**：新增远程规则集订阅与管理，支持 source JSON / binary SRS、启用/禁用、手动及后台更新；由 App 直连下载、校验并管理缓存，更新失败保留上一份有效缓存。
- **Material 3 界面**：基于现有 Android Views/XML 更新主题、配色和控件样式。
- **DNS 修复**：修复成功回调已获得结果却仍等待超时的问题。
- **Geo 规则修复**：修复同一规则包含 GeoSite 与 GeoIP 时条件被覆盖、引用缺失导致配置无效的问题，保持 OR 地址组语义。
- **主界面修复**：修复 StatsBar 上下文转换崩溃、浅色状态栏内容不清晰、连接后停止按钮不可见，以及连接测试失败后仍显示“测试中…”的问题。
- **独立发行签名**：采用本 Fork 自己的长期 Release 签名，包名不变；无法直接覆盖升级原版，首次安装前须先备份并卸载原版。
